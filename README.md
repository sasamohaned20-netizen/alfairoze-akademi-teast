# ALFAIROZE AKADEMI | أكاديمية الفيروز
### منارة المهارات — منصة امتحانات الحساب الذهني

منصة امتحانات خفيفة، سريعة، ومصممة خصيصاً للموبايل (Mobile-First) لاختبارات الأطفال في برنامج الحساب الذهني والسوروبان بالأكاديمية.

---

## 🌟 الميزات الرئيسية

- **Mobile-First & Zero-Scroll**: واجهة محسنة 100% للهواتف الذكية بدون أي شريط تمرير أو تشتيت للطفل.
- **بنك أسئلة عشوائي**: اختيار 100 سؤال عشوائياً من بنك الأسئلة في كل محاولة، بترتيب مختلف تماماً في كل مرة.
- **مسائل الحساب الذهني (Soroban Column)**: عرض عمودي واضح للأرقام والإشارات مع إمكانية تبديل الإشارة `±` للنتائج السالبة.
- **كيبورد رقمي مخصص (Custom Numeric Keyboard)**: لوحة لمسية بأزرار كبيرة سريعة الاستجابة، مع دعم كامل للوحة المفاتيح على أجهزة الكمبيوتر.
- **مؤقت ذكي ضد التحايل (Anti-Refresh)**: مؤقت 5 دقائق محمي يحسب الوقت المنقضي من بداية الاختبار حتى لو تم تحديث الصفحة.
- **تسليم تلقائي وتأكيد إنهاء**: إنهاء تلقائي عند وصول الوقت إلى 00:00، ونافذة تأكيد عند الرغبة في الإنهاء المبكر.
- **تصحيح فوري ومعادلة النتيجة**: حساب دقيق للأسئلة (الصحيحة + الخاطئة + غير المجابة = 100).
- **إرسال النتائج إلى Telegram Bot**: خادم آمن يرسل تقرير النتيجة الكامل إلى بوت التيليجرام دون كشف المفاتيح في المتصفح.

## 🚀 التثبيت والتشغيل المحلي

1. **تثبيت الحزم**:
   ```bash
   npm install
   ```

2. **ضبط ملف البيئة (.env)**:
   أنشئ ملف `.env` (أو عدل الملف الحالي):
   ```env
   TELEGRAM_BOT_TOKEN=توكن_البوت
   TELEGRAM_CHAT_ID=الـ_Chat_ID
   PORT=3001
   ```

3. **تشغيل المشروع**:
   ```bash
   npm run dev
   ```
   - واجهة الامتحان: `http://localhost:5173`
   - خادم التيليجرام والـ API: `http://localhost:3001`

4. **البناء الإنتاجي**:
   ```bash
   npm run build
   ```
